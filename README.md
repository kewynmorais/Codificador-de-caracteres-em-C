# Codificador-de-caracteres-em-C
Projeto acadêmico desenvolvido em C na graduação em Cibersegurança da UFLA. Implementa um sistema de codificação e decodificação de caracteres utilizando a tabela ASCII, fatores associados e operações matemáticas. O projeto aborda manipulação de caracteres, estruturas de dados e lógica de programação.
